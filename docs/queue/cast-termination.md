# 吟唱终止

> 上级：[队列与回合](README.md) ｜ 源码：`GamingQueue.Casting.cs`、`GamingQueue.cs` ｜ 测试：`CastTerminationTests`

普通魔法与协同魔法通过内部 `TerminateCast` 清理施法上下文、状态和顺延奖励。调用点负责硬直策略、通知和外发，终止入口不扣决策点、不改配额或回合计数。

## 硬直规则

`r` 是终止时的剩余吟唱时间；`x` 是协同确认时冻结的原队列硬直，普通魔法为 0；`c` 是 `EquilibriumConstant.CastFailureHardnessTime`，默认 3，与协同确认硬直常数独立。

| 发生阶段及原因 | 普通魔法 | 协同魔法 |
| --- | --- | --- |
| 他人回合或回合外，技能打断 | 保持 `r` | `x+r` |
| 他人回合，全部目标丢失 | `min(r,c)` | `x+min(r,c)` |
| 回合外，全部目标丢失 | 保持 `r` | `x+r` |
| 自己的结算回合，失败或释放前被打断 | 失败尝试计 `c`，随后按正常规则重决、聚合 | 同左，最终聚合再加一次 `x` |
| 被预释放爆发技覆盖 | 无失败补偿，位置由预释放流程设置 | 同左，不恢复 `x` |
| 死亡或移出队列 | 清理生命周期，不重新入队、不产生失败补偿 | 同左，不恢复 `x` |

协同发动钩子先于队列时间替换，此阶段的 `r` 使用本次魔法的实际吟唱时间。队列更新保留两位小数及同时间冲突的排序偏移。

目标不可选和目标死亡都会移除失效目标。仍有目标时继续吟唱；非指向性魔法只有保留目标格且允许空地施法时，才能在没有角色目标的情况下继续。

## 失败尝试与重新决策

结算失败保留 `decided = true`，让当前尝试完成统一硬直入账、动作完成钩子及即时外发；不强制结束回合。后续行动受当前控制状态、剩余 DP、配额和正常决策规则限制，不恢复预算或额外扣失败费用。

普通结算保留发起回合的计数，协同结算入口清空已消费的旧计数。失败尝试的 `c` 始终参与通用聚合，即使后续成功动作的硬直为 0；成功释放 0 硬直魔法本身不应用失败补偿。

若失败后再次发起魔法，新的吟唱保持自身 `CastTime`，原硬直 `x` 顺延到最终释放或外部终止时再还原，不加到新吟唱时间中。新魔法是角色自己的动作，不继承已失败协同申请的归属或辅助关系。

回合开始和行动开始钩子可以提前终止当前施法。队列保留一次待消费的失败记录，由主循环完成失败尝试；不向队列提前重加当前角色。释放前免疫检查若终止施法，也不会继续扣 MP 或释放保存的局部技能数据。

## 状态、奖励和回放

终止时先摘掉 `Casting`，再重算控制状态。角色有控制特效时维持对应状态，不强行变成可行动。预释放爆发技对普通技能打断不可驱散；死亡和移出显式清除预释放状态及待释放技能。

全部终止原因都会立即回收已顺延的被动奖励。上下文先于奖励回收钩子摘除，重复打断或回调重入不会重复回收、通知或恢复原硬直。

技能打断、全部目标丢失和资源不足记录施法者失败，保留技能与协同归属。施法者当前释放或发动尝试复用相应记录；他人回合中新建独立施法者记录，打断者当前动作保持自己的执行结果。外部取消的剩余队列时间不作为单次动作硬直写入失败记录；自己回合的失败尝试硬直为 `c`。

预释放覆盖和移出只记取消原因，死亡由既有死亡记录承载。被阻止的打断不清上下文、不改硬直、不发成功打断通知。资源不足、预释放覆盖和移出不新增技能打断事件。
